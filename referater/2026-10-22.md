## Kort resumé

Sessionen fortsatte arbejdet på GIHC-hjemmesiden fra 21. oktober. Der blev
gennemført en række mindre indholds- og identitetsrettelser, forbedret sociale
previews og tilføjet links til CS Unplugged og GIHC Mini-Mesh. Alle
websiteændringer blev testet, bygget gennem GitHub Actions, SHA-pinnet og
deployeret til produktion.

Hjemmesiden er fortsat tilgængelig på:

- `https://gihc.online/` — dansk
- `https://gihc.online/en/` — engelsk

- Opdaterede downloadkortet til “Broderi & skjortemærke” og
  “Embroidery & shirt patch”.

- Tilføjede den engelske formulering “Children are welcome to bring an adult”.
- Erstattede den private offentlige kontaktadresse med

### Visuelle assets

### Sociale previews

- Producerede `src/assets/gihc-og.png` i 1200 × 630 px som fladt RGB-PNG
  uden transparens.
- Centrerede det officielle GIHC-emblem på baggrundsfarven `#f3eddd`.
- Tilføjede `og:image:type`, `og:image:width`, `og:image:height`,

## Release og drift

- Hver websiteændring blev committet separat.
- GitHub Actions-workflowet “Publish website image” og Trivy-gaten bestod
  for alle website-images.
- Produktionsmanifestet blev opdateret til det relevante SHA-tag efter hver
  vellykket CI-kørsel.
- Deployment blev udført via SSH-tunnel på port 16443, så lokal k3s på port
  6443 ikke blev berørt.
- Den offentlige smoke-test bestod efter hver udrulning.
- Produktionsmanifestet peger ved handover på website-image `dbb2b98`.

## Test og verifikation

- `npm run check` bestod efter indholds-, template- og assetændringer.
- Dansk og engelsk blev visuelt kontrolleret ved cirka 1440 px og 390 px.
- `scripts/smoke-test.sh https://gihc.online` bestod efter alle deploys.
- MIME-typer, TLS, sikkerhedsheadere, health endpoint og 404-side blev
  kontrolleret.
- Den offentlige mærkepakke blev sammenlignet byte for byte med den lokale.
- Den offentlige Open Graph-PNG blev sammenlignet byte for byte med den
  lokale fil.
- Eksterne links blev kontrolleret med HTTP 200.

## Sikkerhed og data

- CSP, sikkerhedsheadere, health checks, non-root-container, read-only
  rootfilsystem, dropped capabilities og SHA-pinning blev bevaret.
- GitHub Actions og Trivy-gaten blev brugt til alle website-images.
- Den private recovery-adresse til Migadu blev ikke ændret og er ikke
  gengivet i dette referat.
- Ingen credentials eller private nøgler blev skrevet til repository.

## Udestående punkter

1. Opret eventuelt en Meta-app og tilføj dens numeriske `fb:app_id`, hvis
   Facebooks valideringsadvarsel skal fjernes.
2. Kør `https://gihc.online/` gennem Sharing Debugger efter metadataændringen
   og genopslå linket, hvis et ældre Facebook-preview fortsat caches.
3. Analysér de fulde Gmail-headers fra mailen, der endte i spam.
4. Fortsæt opvarmningen og test af `mail@gihc.online`.
5. Stram DMARC først efter dokumenteret headeranalyse.
6. Undersøg DNSSEC hos Simply.com.
7. Fortsæt kontaktrunden i `samarbejdspartnere.md`.
