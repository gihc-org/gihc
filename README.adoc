== Hjemmeside

Hjemmesiden ligger i `site/` og serveres som statiske filer fra en
Nginx-container. Kubernetes-manifesterne ligger i `k8s/`.

[source,bash]
----
# Lokal forhåndsvisning
python3 -m http.server 8080 --directory site

# Byg container lokalt
docker build -t ghcr.io/gihc-org/gihc:latest .

# DNS og deploy (kræver pass, SSH-nøgle og åben tunnel til k3s)
./scripts/create-dns-record.sh
ssh -L 6443:localhost:6443 -N -f root@65.109.233.92
./scripts/deploy.sh
./scripts/smoke-test.sh
----

NOTE: På udviklingsmaskinen er port 6443 allerede optaget af det lokale
k3s-cluster. VPS-tunnelen skal derfor bruge 16443; ellers forsøger `kubectl`
at tale med det lokale cluster, og kubeconfig-certifikatet passer ikke.

Kontrollér en eventuel konflikt med:

[source,bash]
----
ss -ltnp | grep 6443
----

Åbn VPS-tunnelen på den ledige port og deploy:

[source,bash]
----
ssh -L 16443:localhost:6443 -N -f hetzner-k3s
KUBECTL_SERVER=https://127.0.0.1:16443 ./scripts/deploy.sh
----

Manifesterne kan også anvendes samlet med:

[source,bash]
----
kubectl apply -k k8s/
----

Ved push til `main` bygger `.github/workflows/publish.yml` et image til
`ghcr.io/gihc-org/gihc:latest`. Siden er tilgængelig på
https://gihc.online[gihc.online].

Produktionsmanifestet pinner image med den commit-SHA, som imageet blev bygget
fra. Ved en ny release opdateres tagget i `k8s/deployment.yaml`; det giver
samme rollback-mønster som `loft-prod`:

[source,bash]
----
IMAGE=ghcr.io/gihc-org/gihc:<commit-sha> ./scripts/deploy.sh
----
