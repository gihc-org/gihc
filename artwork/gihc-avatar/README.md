# GIHC avatar

Forenklet avatar baseret på GIHC-mærket.

## Filer

- `gihc-avatar.svg` — ren SVG til redigering og videre brug
- `gihc-avatar-512.png` — 512 × 512 PNG til GitHub og andre profilbilleder

## Brug på GitHub

GitHub accepterer normalt ikke SVG som profilbillede. Upload derfor
`gihc-avatar-512.png`.

1. Åbn GitHub **Settings → Public profile → Avatar**.
2. Upload `gihc-avatar-512.png`.
3. Justér beskæringen, så hele den runde ramme er synlig.
4. Gem ændringen.

Avatar-versionen bruger kun de vigtigste visuelle elementer fra mærket:

- solen
- teltet
- bålet
- landskabet
- GIHC-navnet

Den er derfor mere læsbar ved meget lille visning end den detaljerede
broderi-SVG.
